## 🚀 Proyectos Destacados

**[ArgEcon AI](https://github.com/Nicocc12/argencon-ai)** — `Python` `FastAPI` `LLaMA 3` `IA`
Agente de análisis económico argentino en tiempo real. Consume las APIs del BCRA y dolarapi.com para obtener cotizaciones, reservas y variables monetarias. Calcula inflación acumulada de los últimos 12 meses y genera análisis automáticos con LLaMA 3 vía Groq AI.

**[Gestión Maratón 2026](https://github.com/Nicocc12/maraton-ituzaingo-web)** — `PHP` `MySQL` `JavaScript`
Plataforma web para la Municipalidad de Ituzaingó. Inscripción de corredores, panel de administración, generación automática de QR y envío de emails de confirmación.

**[E-commerce App](https://github.com/Nicocc12/ecommerce-mobile-react-native)** — `React Native`
Réplica funcional de Frávega desarrollada en React Native. Navegación Drawer, catálogo dinámico, perfil de usuario e historial de compras.

**[Sistema de Biblioteca](https://github.com/Nicocc12/sistema-biblioteca-java)** — `Java` `POO`
Sistema de escritorio para gestión de préstamos con herencia en POO, validación por DNI y migración de datos desde Excel.
